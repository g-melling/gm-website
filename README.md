# Musician Portfolio Website

A responsive personal portfolio website showcasing background, projects, skills, and professional experience.

## Overview

This website serves as my online musician portfolio, providing visitors with information about work, creative projects, and professional journey. The site is designed to be clean, responsive, and accessible across desktop and mobile devices.

## Features

* Responsive design for desktop, tablet, and mobile devices
* Modern user interface
* Project and portfolio showcase
* About Me section
* Contact information and social links
* Interactive elements powered by JavaScript
* Fast-loading static website architecture

## Built With

* **HTML5** – Structure and content
* **CSS3** – Styling, layout, and responsive design
* **JavaScript** – Interactive functionality and dynamic content
